# MyTelescope
**Status:** Activ | **Data Start:** 2026-04-26

## 1. Scop și Obiective
* Transcriere/portare aplicație desktop scrisă în Free Pascal într-o aplicație web mobilă
* Obiectiv principal: accesibilitate pe orice dispozitiv (telefon, tabletă) fără instalare
* Păstrarea funcționalității originale, adaptată la interfață touch/responsive

## 2. Livrabile
* Aplicație web mobilă funcțională (HTML/CSS/JS sau framework modern)
* Paritate de funcționalitate cu versiunea Free Pascal originală
* Documentație tehnică a procesului de portare

## 3. Riscuri și Dependențe
* Complexitatea codului Pascal original (logică, algoritmi specifici telescopului)
* Alegerea stack-ului web potrivit (vanilla JS vs React/Vue/Svelte)
* Compatibilitate cross-browser pe dispozitive mobile
